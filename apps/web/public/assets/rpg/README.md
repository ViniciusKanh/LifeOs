# Assets do tema RPG

Fonte única de imagens do tema RPG. Componentes referenciam estes arquivos só via
`src/components/rpg/rpgAssets.ts`.

- `logo/` — logo pixel art aprovado (`logo-full.webp`) e versão compacta do orbe (`logo-icon.webp`).
- `avatars/` — retratos aprovados dos personagens (384 px e `-sm` 128 px, WebP).
- `banners/` — paisagens pixel art provisórias (geradas a partir de 384×96 ampliado 4× sem suavização). Podem ser trocadas por artes oficiais com o mesmo nome.
- `backgrounds/` — textura de fundo quase imperceptível (tile 128 px).
- `icons/`, `frames/`, `achievements/`, `items/` — reservadas para os próximos assets aprovados.
